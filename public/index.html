KANTOR DI KOMPUTERMU

Codex bekerja. Kamu mengamati.

Jalankan npm start, lalu buka http://localhost:4173. Biarkan terminal server tetap menyala.

  1. Gunakan Codex CLI seperti biasa di folder proyekmu.
  2. Pembaca memeriksa ~/.codex/sessions setiap 5 detik. Jika kamu memakai CODEX_HOME, folder itu yang digunakan.
  3. Folder kerja sesi menjadi ruangan. Satu sesi menjadi satu karakter; ini bukan bukti bahwa prosesnya masih berjalan.

“Giliran dimulai” dan “selesai” mengacu pada event log. Jika log berhenti diperbarui, status menjadi tidak pasti. Aplikasi tidak mengirim tugas atau membaca isi prompt ke tampilan.

Untuk direktori khusus: npm start -- --codex-home "/path/.codex". Tambah konteks melalui --config workspace.local.json; lihat README.

Dunia contoh memakai data fiktif. Gerakan, percakapan, dan istirahat karakter selalu dekoratif.
